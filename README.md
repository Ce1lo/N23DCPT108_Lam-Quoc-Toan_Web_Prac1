# N23DCPT108_Lam-Quoc-Toan_Web_Prac1

Ho ten: Lam Quoc Toan
MSV: N23DCPT108

Blog Listing Page — NextJS (App Router) & Tailwind CSS.

## Chay du an

```bash
npm install
npm run dev
```

Mo [http://localhost:3000](http://localhost:3000) de xem trang danh sach bai viet.

## Cau truc

- `app/page.js` — Server Component fetch 12 bai viet tu JSONPlaceholder, hien thi grid responsive.
- `app/blog/[id]/page.js` — Trang chi tiet bai viet theo id.
- `components/Header.js` — Header dung chung.
- `components/Badge.js` — Component tai su dung.
- `components/BlogCard.js` — The bai viet.
